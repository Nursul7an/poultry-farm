# Директору: запуск фермы в приложении (≈ 30 минут)

1. **Войдите** со своим телефоном и PIN. На пустой ферме сразу откроется «Настройка фермы».
2. **Шаг 1 · Ферма.** Проверьте название и час начала производственных суток (обычно 8:00 — с утреннего обхода). «Дальше».
3. **Шаг 2 · Птичники.** Нажмите «Добавить П-1, П-2, П-3, П-4» (число и площадь можно поменять). «Дальше: работники».
4. **Шаг 3 · Работники.** Имя, телефон, отметьте его птичники. PIN приложение придумает само. После «Добавить работника» появится карточка с телефоном и PIN — нажмите **«Скопировать для WhatsApp»** и отправьте работнику. PIN показывается один раз.
5. **«Готово».** Первая посадка открывает партию: её записывает работник («Ещё → Посадка») или вы.

## Потом: «Ещё → Ферма и люди»
| Нужно | Где |
|---|---|
| Работник забыл PIN | работник → «Новый PIN» → отправить новый PIN. Старый сразу перестаёт работать. |
| Работник ушёл | работник → «Отключить работника». Войти не сможет, его записи остаются. «Вернуть доступ» — если вернулся. |
| Перевести на другой птичник | работник → отметить птичники |
| Сменить телефон работника | работник → «Изменить имя или телефон» (это его логин, PIN прежний) |
| Новый птичник | «+ Добавить птичники» |
| Птичник не используется | птичник → «Отключить» (удалить можно только птичник без истории) |
| Название фермы, начало суток | «Ферма» → нажать на строку фермы |

Все действия с людьми видны в «События → Люди». Настройка работает только при наличии интернета.
