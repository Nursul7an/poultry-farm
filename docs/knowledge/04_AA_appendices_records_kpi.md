## Прил. 3 — Формулы KPI
- **EPEF (PEF)** = Сохранность % × ЖМ (кг) / (Возраст (дн) × FCR) × 100. Пример: 42 дн, 2.652 кг, отход 2.80%, FCR 1.75 → **351**. Сравнивать стада одного убойного возраста.
- **CV%** = SD / средняя ЖМ × 100 (2550 г, SD 250 → 9.8). Чем ниже, тем лучше.
- **FCR** = общий корм / общая ЖМ.
- **Приведённый FCR** = факт FCR + (нормативная ЖМ − факт ЖМ) / 4.5 кг (смешанный пол). Корректно только при разнице ≤ ±0.227 кг.
- **Рабочая (эффективная) температура** = мин t + 2/3 × (макс − мин). 16/28 → 24 °C.
- **Число ламп** = площадь (м²) × макс. люкс / (мощность лампы × K); K: 15Вт 3.8 · 25Вт 4.2 · 40Вт 4.6 · 60Вт 5.0 · 100Вт 6.0 (вольфрам, 2 м).

## Прил. 4 — Пол по оперению
Маховые длиннее кроющих → курочка (быстрооперяющаяся); равны или короче → петушок.

## Прил. 5 — Решение проблем (→ правила подсказок в приложении)
| Проблема | Причины | Действия |
|---|---|---|
| Ранний отход > 1% за 1-ю неделю | качество цыплят; брудер; болезни; аппетит | инкубация и гигиена яиц; положение брудеров; вскрытие + ветврач; зоб, объём и фронт кормления |
| Отход после 7 дн | метаболические (асциты, ВСС); инфекции; ноги | вентиляция, рацион, избегать быстрого раннего роста; вскрытия, ветврач; вода, Ca/P/D3, свет для активности |
| Низкий рост/однородность в начале | рацион; качество цыплят; условия; аппетит; болезни | старт-корм, вода, t/ОВ, свет, CO2, пыль, мин. вентиляция, зоб, вскрытия |
| Низкий рост/однородность позже | мало питательных веществ; инфекции; условия | рацион, доступ к корму, избыточное ограничение корма/света; вентиляция, плотность, t, вода/корм |
| Плохая подстилка | жир, соль, протеин, мало подстилки; поилки льют; ОВ, плотность, вентиляция; энтериты | по пунктам |
| Плохой FCR | плохой рост, отход, потери корма, низкая t | высота кормушек, доедание 2 раза/день, t |
| Плохая оперяемость | высокая t, метионин+цистин | |
| Брак на переработке | асциты; натоптыши (плотность, подстилка); синяки/переломы (отлов, взвешивание); царапины (свет, фронт); миопатия (стресс); избыточная ЖМ | |

## Чего НЕТ ни в одном файле (нужно получить отдельно)
- **Нормативы продуктивности Arbor Acres (Performance Objectives):** ЖМ, привес, потребление корма и FCR по дням. Это отдельный буклет Aviagen, без него приложение не сможет показывать «факт vs норма».
- **Спецификации рационов AA:** полная питательность по фазам (есть только заголовки).
- **Схема вакцинации по дням:** зависит от ветврача и региона.
- **Срок санразрыва в днях, сроки ожидания препаратов:** по местному законодательству.
